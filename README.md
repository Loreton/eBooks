# Ebook Processor

A Python package for processing EPUB files with advanced features for author normalization, duplicate detection, and file organization.

## Features

- 📚 Extract metadata (title, authors, publisher, etc.)
- 🔍 Search text within EPUB files
- 📁 Organize books by author
- 🔄 Normalize author names (handle different formats)
- ⚠️ Handle filename conflicts
- 🚀 Skip duplicate content
- 📊 Generate reports
